FULL-STACK / PYTHON · MCA ACADEMIC PROJECT
QueueLess: Smart Virtual Queue Management System
GOALReplace physical queues with digital daily tokens, live tracking and an explainable waiting-time estimate.
BUILTA Flask + MongoDB web app with three roles. Students join, track and cancel tokens. Staff run the queues of the services assigned to them. Admins manage services, counters, users and roles, and see analytics and an audit log. It also has a public display board.
QUEUESENSEA rule-based, explainable waiting-time estimator (not machine learning). It averages the last 50 completed visits and shows a “be ready around X to Y” window, always labelled approximate.
ENGINEERINGQueue position is derived, never stored. Partial unique indexes guarantee one active token per student per service per day. Token numbers come from atomic counters. Security covers password hashing, CSRF protection, server-side role checks, rate limiting and an audit log.
